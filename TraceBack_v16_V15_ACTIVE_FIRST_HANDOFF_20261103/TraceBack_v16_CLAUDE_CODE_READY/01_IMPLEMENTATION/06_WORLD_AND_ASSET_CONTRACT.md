# 맵/에셋 제작 계약
- 기존 164MB 전체 에셋은 `04_ASSETS` 보관; 필요한 개별 이미지만 추출해서 Claude 컨텍스트 비용 최소화.
- 참고 이미지·sprite sheet·사진은 3D geometry가 아니다. 실제 glTF/FBX 있으면 파일별 검증. 없는 경우 메시/primitive로 코지 스타일 차량/캐릭터 제작한 뒤 교체 가능하게 분리.
- 도로: 충분한 폭·커브/차선, 장애물·충돌 콜라이더, 항구 진입, 마지막 램프. 최소 5개 환경 구역이 고유 시각 테마를 가져야 함.
- 환경 밀도: 도로 옆 상점, 창고, 컨테이너 높이 차, 크레인, 화물차, 가로등, 난간, 간판, 바다, 배, 스카이라인. 빈 벌판/반복하는 텍스처/벽 없이 공허한 도로 금지.
- 카메라: 속도감, 코너 따라 회전, 충돌 피드백, 저 FPS에서도 delta 독립 감쇠. UI는 Pretendard 우선(라이선스 확인), 대체 폰트 허용.
- 고양이 2명 얼굴 형태는 원본 참고, 점눈·통통하고 목 구분, 기존 승인 이미지와 가깝게. 기존 이미지를 실제 3D 에셋이라고 주장하지 않음.
- 개별 시안이 서로 다르면 결정 레지스트리에 표시하고 임의 혼합 자제. 필요할 경우 일관된 스타일 원칙으로 정리하되 '결정 필요' 보고.
