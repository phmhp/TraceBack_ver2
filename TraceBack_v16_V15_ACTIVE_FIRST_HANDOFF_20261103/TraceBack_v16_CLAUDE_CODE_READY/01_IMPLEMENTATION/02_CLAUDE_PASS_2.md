# CLAUDE CODE — PASS 2 (첫 구현 리뷰 후)

PASS 1의 `REPORTS/` 전부와 사용자가 남긴 수정 의견을 먼저 읽고, 거기에 적힌 P0 실패를 우선 해결. 첫 구현의 구조를 이유 없이 갈아엎지 않는다. `05_SCENARIOS/` 데이터 스키마를 재사용하여 열관리 사건을 추가하고, 제동 사건은 준비 가능한 경우에만 선택형으로 추가.

- 열관리: 시간/상태/히스테리시스·팬 명령 vs 실제 피드백을 시계열 시험으로 검증.
- 제동: 회생 제한→마찰 보완과 실제 응답을 통합 시험으로 검증. 결함 주입/기대값이 미검증이면 PROPOSED로 표시하고 플레이 가능한 정답으로 쓰지 않음.
- 레이싱/맵/에셋/애니메이션/성능·HUD 결함 개선. 실제 이미지 비교 캡처와 누락 목록 기록.
- 실제 v14 최신 코어 교체 시 버전/신호 매핑/타이밍/테스트 재확인; 이전 결과를 그대로 복사 금지.
- 사용자가 승인하지 않은 결말·체포 규칙은 분기 가능 형태로 남김.
- `REPORTS/`의 전 항목을 갱신하고 새로 생긴 모호함과 미구현을 반드시 보고.
