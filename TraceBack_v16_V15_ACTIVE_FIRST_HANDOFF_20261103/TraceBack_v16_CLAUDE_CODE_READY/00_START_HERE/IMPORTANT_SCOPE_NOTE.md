# 필수 확인 — 대용량 파일 보존 안내

이 경량 단일 ZIP은 개발에 필요한 모든 **인계 계약/현행 v14/최종 Stitch HTML 22개/고장 사례 11개/초기 선별 에셋 35개**를 담았다.
하지만 **원본 에셋 전체 `TraceBack_Organized 3(1).zip` 및 추가 Stitch 이미지 `(15)`~`(21)` 일곱 ZIP 원본 전체를 포함하지 않는다**. 용량 문제로 통합 ZIP 전송에 실패해, 해당 8개 대용량 원본의 이름·크기·SHA256 및 참조 이미지 색인을 수록했다. 초기 구현은 이 ZIP 자체로 시작하고 추가 원본이 필요하면 사용자가 원본을 같은 폴더에 놓도록 요청하라.
참고용 2D 이미지가 실제 3D 모델이라고 주장하지 말 것. 추가 원본 전체가 포함됐다고 사용자에게 말하지 말 것.
