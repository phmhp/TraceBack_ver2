# ChatGPT 에셋 제작 요청문

아래 문장을 복사해 이 ZIP과 함께 전달하세요.

---

첨부한 ZIP은 현재 구현된 3D 웹게임 `TraceBack`의 전체 UI 화면 42장이다. 먼저 `SCREEN_INDEX.md` 순서로 모든 화면을 분석해라. 이 게임은 신입사원이 EV 차량 도메인, 시스템/E/E/SW 관점, 고장 추리, 제어 경로 복원, 요구사항 기반 검증을 추리·레이싱 게임 흐름 속에서 배우는 교육용 게임이다.

목표는 와이어프레임과 현재 정보 구조를 유지하면서 UI와 그래픽을 상용 게임 데모 수준으로 높이는 것이다. 스타일은 따뜻하고 둥근 3D 라이프 시뮬레이션 감성, 수공예 질감, 읽기 쉬운 전시용 UI다. 단, 차량 부품·ECU·센서·액추에이터·배선·검증 장비는 장난감 도형이 아니라 실제 EV 부품과 구조를 참고한 설득력 있는 형태여야 한다.

먼저 다음을 작성해라.

1. 화면별 문제점과 재사용 가능한 공통 컴포넌트
2. 새로 필요한 에셋 인벤토리와 우선순위
3. 에셋별 권장 크기, 비율, 투명 배경 여부, 9-slice 여부
4. 일관된 색·재질·조명·모서리·그림자 규칙
5. 글자를 이미지에 굽지 않고 HTML/CSS로 얹기 위한 안전 영역

그다음 가장 우선순위가 높은 에셋부터 한 번에 하나씩 생성해라. 화면 전체 목업 한 장만 만들지 말고 실제 구현에 바로 쓸 수 있게 분리된 투명 PNG 또는 텍스처로 제공해라. 동일한 고양이 두 캐릭터, 붉은 오픈카, 경찰차, 폴라로이드, 버튼/탭/패널 프레임의 스타일을 모든 에셋에서 고정해라.

우선 제작 후보:

- 공통 3D 버튼 플레이트: 기본/호버/눌림/비활성
- 공통 패널·탭·토스트·모달 프레임
- 실제 종이 두께와 필름 질감이 느껴지는 폴라로이드 프레임
- 증거 보드용 압정·연필·지우개·실·커서
- 차량 도메인 학습용 실제형 EV 부품 컷아웃과 ECU/하네스
- 검증 실험실용 칠판·비교 보드·테스트 케이스 카드
- 레이싱용 자차·경찰차·일반 차량·도로변 환경
- 최종 부두의 나무 오르막 램프·해적선 갑판·점프 연출용 배경

최소 본문 글자 16px, 보조 글자 13px 이상을 전제로 구성하고, 노안이 있는 전시 관람객도 1m 거리에서 주요 상태와 버튼을 읽을 수 있게 대비와 여백을 잡아라. 작은 글씨로 정보를 억지로 채우지 말고, 상세 설명은 확대·도움말·단계적 공개로 분리해라.
