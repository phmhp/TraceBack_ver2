- 총 화면: 42장

1. 타이틀·프롤로그
2. 차량 도메인 학습: 7개 도메인 × 차량 시스템/E/E/제어 SW 3개 관점
3. 부잣집 탈출 애니메이션 2개 시점
4. 레이싱·고장 대화
5. 증거 메모판·제어 경로 복원 퍼즐
6. V-모델 검증 실험실 4개 탭과 실패 해설·수리
7. 주행 복귀·최종 부두·해적선 점프/착지·검거·일시정지·엔딩

파일별 설명은 `SCREEN_INDEX.md`, 바로 붙여 넣을 에셋 제작 요청문은 `ASSET_REDESIGN_PROMPT_KO.md`를 확인하세요.

## 에셋 제작 시 중요 조건

- 와이어프레임의 정보 구조와 게임 흐름은 유지하고, 임의로 페이지 구성을 바꾸지 않습니다.
- 화면 전체를 한 장의 이미지로 다시 만들기보다, 실제 구현에 쓸 수 있는 분리 에셋을 우선합니다.
- 버튼·패널·탭·폴라로이드 프레임은 9-slice 또는 충분한 여백을 가진 투명 PNG로 제작합니다.
- 이미지 안에는 한글 문구를 굽지 않습니다. 글자는 HTML/CSS로 표시합니다.
- 동물의 숲처럼 둥글고 따뜻한 3D 질감을 사용하되, 차량 부품과 검증 장비는 교육용 장난감이 아니라 실제 EV 구성과 닮은 재질·형상으로 만듭니다.
- 같은 고양이 캐릭터, 같은 붉은 오픈카, 같은 경찰차와 동일한 색·재질 체계를 모든 화면에서 재사용합니다.
