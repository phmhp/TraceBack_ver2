# 현실 도로 상황·조건·게임 요소 카탈로그 (설계 자료, 구현 전)

레이싱 개편과 고장 사건 설계의 재료입니다. 한 사건·한 레벨에 모두 넣지 않고, 레벨마다 몇 개만 골라 씁니다.
열 설명: **차량 반응**은 EV가 정상일 때 하는 동작(정상 동작 학습), **고장 연결**은 이 상황이 고장의 트리거·스트레스가 될 수 있는 도메인, **분류**는 활용 방식입니다.
분류 기호: ◆ 고장 트리거 후보 / ○ 정상 동작 학습 / △ ADAS 계열 한정 / ▽ 환경 연출만(EV 고장과 직접 관계 약함)

## E. 날씨·시간·시계
| 조건 | 차량 반응 | 고장 연결 | 분류 |
|---|---|---|---|
| 비·젖은 노면, 수막현상 | ABS·TCS·ESC 개입, 감속 | 슬립 판단(ABS 임계), 구동력 제한 | ◆ |
| 폭우 | 시야 저하, 와이퍼 | - | ▽ |
| 안개·미세먼지·황사 | 시야 저하, 센서 오염 | 인지 성능(ADAS) | △▽ |
| 눈·서리·빙판·블랙아이스 | 슬립 개입, 구동력 제한 | ABS·TCS | ◆ |
| 강풍(횡풍) | 조향 보정 | 조향·ESC | ○ |
| 폭염 | 냉각·에어컨 부하 | 열관리(연속 고부하) | ◆ |
| 한파 | 배터리 출력 제한, 히터 전력으로 주행거리 감소 | 전원·열관리 협조(전력 예산) | ◆ |
| 야간·전조등·상향등 | 자동 라이트, 눈부심 | - | ▽ |
| 역광·석양·터널 출구 눈부심, 젖은 노면 반사 | 카메라 노출 | 인지 성능(ADAS) | △ |
EV 고장과 직접 관계가 약한 것(야간, 미세먼지, 역광)은 **ADAS 사건**이 아니면 분위기·난이도 요소로만 씁니다. 고장 트리거로 쓰기 좋은 것: 비·빙판(슬립 판단), 한파·폭염(열·전력 협조).

## G. 차량 상태·운전 보조
저SOC·주행 가능 거리 불안, 급속/완속 충전 정차, 충전 중 문제, 타이어 공기압 경고, 12V 방전, 도어·안전벨트 경고, 오토홀드·크리프, 원페달 주행(회생 단계), 크루즈 컨트롤, 차선 유지·이탈 경고, 사각지대·후측방 경고, 전방 충돌 경고, 자동 긴급 제동, 언덕 밀림 방지, 자동 주차.
## H. 법규·평가
제한속도(일반·스쿨존·고속), 신호·차선·안전거리·양보 의무 준수, 야간 전조등, 경적 사용 제한, 과속·신호 단속.

## 현실 기반 게임 요소 (아이템·부스터 없이)
| 요소 | 설명 |
|---|---|

| 에코(회생) 점수 | 회생 활용, 부드러운 가감속(저크) |

| 경로 선택 | 최단 vs 안전 우회, 정체 구간, 검문·도로 폐쇄 |
| 시간 압박 | 도착 시간, 추격차(이미 있음) |

| 상황 도감 | 만난 도로 상황과 차량 반응을 카드로 수집, 정비소 기능과 연결 |
| 날씨·시간대 변주 | 레벨별 고정(랜덤 아님) 또는 선택 가능한 난이도 옵션 |

| 도로 표지판 | 제한속도·위험 표지로 규칙 인지(정보 제공, 퀴즈 아님) |
| 교통 흐름 | 정체·원활 구간에 따른 추격 거리 변화 |

## 상황 → 고장 도메인 연결표 (고장 사건의 시점·트리거 후보)
| 상황 | 연결되는 도메인과 고장 범주 |
|---|---|
| 신호 대기(정차) | 전원·차량 통합(시동 꺼짐, G·D), 출발 응답(구동, F) |
| 급제동·저속 정지 | 제동 협조(H), ABS(E/J) |
| 긴 내리막 | 회생 협조·부호(J), 제동 열 |
| 한파 | 전원 출력 한계·히터 전력 협조(H) |
| 폭염·정체 고부하 | 열관리(F·G) |
| 젖은 노면·빙판 | 슬립 판단(E), 구동력 제한 |
| 과속방지턱·포트홀 | 현가 댐핑·센서 필터(A·E) |
| 터널 | 통신 타임아웃·E2E(C), ADAS 센서 |
| 언덕 정차 | 변속·주차 해제 조건(D), 밀림 방지 |
| 충전소 정차 | 충전 협상(C·E) |
| 충돌 후 | 정상 HV 차단과 비교(고장 아님) |
