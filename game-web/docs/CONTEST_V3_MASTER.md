# TraceBack 공모전 개선판(contest/v3) 마스터 명세 (요약본)

기준: `refactor/ev-logic-lab-mvp`(dce7e505)에서 분기한 `contest/v3`. 완성도 높은 원본 위에서 선택적 리팩터링. 연속 진행(일차 구분 없음), 대충 하지 않음.
근거 자료: `docs/REQUIREMENT_TRACEABILITY_FINAL_2026-11-10.md`, `docs/FAULT_SCENARIOS_2026-11-09.md`, `docs/STEP02_STEP04_FLOW_BASELINE_2026-11-11.md`, contest/v2의 `docs/ux-captures/CAPTURE_INDEX.md`(화면 인벤토리).

## 절대 원칙
1. 기존 정상 동작·데이터·에셋·스토리·레이싱·퍼즐·시험·저장·엔딩 보호.
2. 새 컴포넌트 전에 기존 컴포넌트 재사용·대체 검토. 기존/신규 UI 중복 유지 금지.
3. 화면 잘림·버튼 가림·진행 불가 = 완료 차단. `overflow:hidden`으로 숨기는 것은 해결 아님.
4. 테스트 통과만으로 UI 정상 보고 금지. 실제 클릭으로 검증.
5. 모델이 계산하지 않은 수치·시험을 시뮬레이션 결과처럼 표시 금지.
6. 장문·반복 객관식보다 그래픽·조작·관찰·비교.
7. 미완료를 완료로 보고 금지. 정답 해설 팝업 금지(DEV는 자동 정답 적용 방식).

## 게임 흐름
타이틀 → 5컷 프롤로그 → STEP01 정비소(동작 원리) → 주행 브리핑 → 레이싱 → 고장 → STEP02 도미노 역추적 → STEP03 정상 기준 조립/시험 준비 → STEP04 실험 검증·수리 → 주행 복귀 → (2번째 고장 반복) → WANTED 보고서 → 엔딩.
사용자 확정 변경: 한 판의 레이싱 비율 증가, 고장 추리는 기본 1문제, 고장 시나리오 다양화(SW 중심 신규 추가).

## 공통 UI
- 정보 위계: 단계 → 목적 → 할 일 → 조작 위치 → 변화 → 의미. 상단 HUD+전체 여정+단계 탭+세부 단계 위치, 미션/질문 1개, 중앙은 그래픽·조작, 하단 고양이 안내+고정 진행 버튼.
- 동일 역할 버튼은 항상 같은 위치. 콘텐츠 양(정답·오답·해설)이 달라도 버튼 이동 금지.
- 1600×900 기준 비례 축소+레터박스. 검증 해상도 1600×900 / 1440×900 / 1428×800 / 1280×720. STEP02·04 문서 스크롤 없음. 세로 화면은 "가로로 돌려주세요" 안내.
- 고양이: 짧은 문장, 다시 듣기, 조작 영역 가리지 않음.

## STEP별 요지
- STEP01: 5개 객관식이 아닌 연속 체험(기능 체험→기계→E/E 신호→Control SW→통합). 세 관점(Vehicle/System, E/E, Control SW) 유지, 입력 상태 공유. 구동 기능을 완성형으로, 다른 도메인은 구조 재사용. 렉 재현·원인 수정.
- STEP02: 증상 확인→출력 선택→역방향 추적→의심 구간→가설 정리. 3열·무스크롤 유지, 최초 편차는 정답 전 비노출.
- STEP03: 요구사항→로직 조립→연결 확인→시험 조건→정상 기준 확정(시험 계약 생성). EARS/INCOSE 참고, 근거 없는 수치 금지.
- STEP04: 가설 시험→최종 원인→A/B 비교→수리→재시험. 요구사항 PASS/FAIL과 가설 지지/반박 구분. 3:4 조작 캔버스, SW 퍼즐 확대/축소/맞춤 유지.
- 기술 정합성: 열관리 PWM 기준·전파, 제동 속도·정지거리, 가설 판정 모순, 신호·단위·기준 불일치 수정.
- 시나리오 데이터 계약: scenarioId, 도메인, 트리거, 결함 활성 조건, 증상, 정상 기준, 최초 편차, 전파 경로, 증거, 가설·함정, STEP02 정답, STEP03 계약, STEP04 입력·관측·오라클, 수리, 재시험, 보고 데이터.
- DEV 메뉴: 왼쪽 하단 소형, 현재 질문 자동 정답·퍼즐 정답 배치·단계 완료·시험 실행·사건/단계 이동·초기화. 기존 `secretSolve` 재사용. 개발 모드 전용(프로덕션 제외).
- 레이싱/엔딩: 분석 중 자차 정지, 경찰차 0.08m/s 접근, 수리 후 재개, 새 게임 시 상태 초기화, 실제 기록만 WANTED 보고서, 도주 장면 HUD 정렬.
