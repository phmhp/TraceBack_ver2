# 작업 목록 (2026-11-09 저녁) — 이번 지적 + 이전 프롬프트 + 마스터 문서

상태: ☐ 할 일 · ☑ 완료(크롬에서 확인) · ✕ 제외(사유)

## A. 차고 · 3D (Vehicle/System)
- ☐ A1 기본 도형으로 남은 부품 전수 조사 → 코드 모델로 교체 (압력 제어기, 유압 라인, 조향각 센서 등 지적 3종 포함, 모든 도메인·기능)
- ☐ A2 부품 크기 = 실제 크기 비례 (한 도메인 안에서 같은 축척. 스프링·시동 버튼이 모터와 같은 크기 금지)
- ☐ A3 부품 위치·각도 = 실제 차 안 배치 (페달은 운전석 발밑, VCU는 대시보드 뒤, 모터·감속기는 앞 차축, 팬은 앞 범퍼 뒤 등)
- ☐ A4 배선 = 부품 포트(커넥터)끼리 실제 경로로 연결 (임의 직선 금지)
- ☐ A5 입력 전: 흐름·애니메이션 없음(정지) → 입력 중: 배선을 따라 흐름이 진행 + 최종 액추에이터 실제 동작
- ☐ A6 전달되는 것 표시: 전기 신호 / CAN 메시지 / 고전압 전력 / 기계 토크 / 유압 / 냉각수 등 (배선 종류별 색·이름표)

## B. 차고 · UI
- ☐ B1 조건 버튼·입력 버튼: 크기·모양·색 통일 (모든 관점 동일)
- ☐ B2 선행 버튼을 눌러도 다른 버튼 위치가 움직이지 않게 (안내 문구는 고정 자리)
- ☐ B3 E/E '보기' 탭이 그림을 가림 → 왼쪽 관점 상자 위쪽으로 이동
- ☐ B4 E/E 본문 상자 크기 = Vehicle/System·Control SW와 같게, 아래 칸이 E/E에서만 커지는 문제 해결
- ☐ B5 E/E '실제 부품' 보기: 사진 아이콘이 아니라 제어기·부품을 블록 상자 경계 위치에 실제 모델로 배치
- ☐ B6 이전 요청 재확인: 팝업 문구, 다음 버튼, 세 관점 역할, 노드 팝업, 깜빡임, 라벨 넘침

## C. 레이싱
- ☐ C1 갑자기 생긴 렉 원인 찾고 해결
- ☐ C2 차가 덜덜거리며 나가는 현상(떨림) 해결 → 부드럽게
- ☐ C3 주행시간 상자 테두리 이상 수정
- ☐ C4 HUD 통일 상태 재확인 (로고·격차·주행시간·백미러·조작법·미니맵·계기판)

## D. 도미노 역추적 (합의안 = PLAY_FLOW_V2 1단계)
- ☐ D1 '처음 어긋난 곳 지목' 방식 폐기 → 합의안: 증거 폴라로이드(틀린 그림 찾기) → E/E 판에서 출력 고르기 → 그 출력에 영향 준 부품만 머그샷 용의자 → 하나씩 재고 플레이어가 반박/유력 도장 → 유력이 새 출력 → 앞이 모두 반박되면 도미노가 쓰러짐 → 의심 구간 → 판단 보류 가설을 검증으로
- ☐ D2 폴라로이드 적용: 기존 폴라로이드 틀·사진 재사용, 클릭 시 설명·원본 기록 크게 보기, 압정
- ☐ D3 '고장 당시 입력 재생' 버튼: 경계선 겹침 수정, 문구는 사건과 무관한 범용 문구
- ☐ D4 오픈북 창이 추격 막대 아래로 깔리는 레이어 문제
- ☐ D5 추격차와의 거리 막대 안쪽 여백
- ☐ D6 다각도 증거(체감·계기판·기록·도로), 안 들여다보기(경계값만), 튜토리얼 하이라이트 유지

## E. 로직 퍼즐
- ☐ E1 겹침·레이어·여백 재점검, 수치 표기 통일
