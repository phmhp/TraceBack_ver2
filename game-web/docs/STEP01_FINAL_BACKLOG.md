# STEP01 최종 통합 검수 백로그 (2026-11-13 추가 요구사항, STEP02~04 개발과 병행하지 않고 통합 검수 단계에서 반영)

1. **도메인 체계 검토**: 현재 STEP01 도메인 7개(구동·제동·조향·전원·변속주차·열관리·현가)가 같은 분류 수준인지, 차량 동역학·ADAS 같은 상위/횡단 영역과의 관계, EV 필수/선택 영역, 시나리오 연결 가능성. 공식 표준 분류와 교육 분류를 구분. 도메인을 무조건 늘리지 않음.
2. **조작형 미션**: 텍스트·선택지 중심에서 조작(페달·센서·조건), 관찰(기계 동작), 연결(E/E 경로), 판단(SW 조건), 비교(ON/OFF) 유형으로 확장.
3. **세 관점 연결 강화**: 같은 입력이 Vehicle → E/E → Control SW 에서 이어지고 신호가 단계별로 이동.
4. **기계 모델·신호 모델 동기화**: 운전자 입력 → 센서 → ECU → 통신 → SW 판단 → 액추에이터 → 기계 동작 → 차량 반응. 계산 가능한 값은 simModel·레지스트리 재사용, 계산하지 않는 영역은 개념 시각화로 명시.
5. **공통 미션 템플릿**(필요성·구성요소·신호·SW 조건·차량 반응)을 검증된 범위 안에서만 적용. 질문 없는 도메인 보완.
6. **모바일 친화 구조**: 큰 조작 영역, 한 번에 하나, 터치. PC 16:9 무스크롤 유지.
