# 추리 3단계 화면 구성·레이아웃 계획 (구현 전 확인용, 2026-11-08)

원칙: 지금 화면(노트 종이 스킨, 폴라로이드, 퍼즐판, 신호 모니터)을 그대로 쓰고 **배치와 역할만** 바꾼다. 새 페이지는 만들지 않는다. 화면은 스크롤 없이 한 장(16:9, 1280×720 이상)에 들어가게 한다.

세 단계를 하나로 꿰는 공통 장치는 **가설 카드 줄**이다. 세 화면 모두 같은 위치(상단 진행 바 바로 아래)에 같은 모양으로 보인다.

```
[가설] [VCU 페달 처리 SW · 판단 보류] [VCU 입력 회로 · 판단 보류] [페달 센서 · 반박됨] [인버터·모터 · 반박됨]
```

## 공통 프레임 (세 단계 동일)

```
┌──────────────────────────────────────────────────────────────────────┐
│ 헤더(장면 이름)                         진행 단계 8칸 · 추격 거리     │
│ ← 이전 / 다음 →   추격 바                                            │
├──────────────────────────────────────────────────────────────────────┤
│ 가설 카드 줄 (누르면 근거)                         [차고 노트] [도움말]│
├──────────────────────────────────────────────────────────────────────┤
│                         단계별 본문 (아래)                            │
├──────────────────────────────────────────────────────────────────────┤
│ 엔지니어 말풍선: 지금 할 일 한 줄                                     │
└──────────────────────────────────────────────────────────────────────┘
```
- **차고 노트**: 지금 차고 페이지를 그 사건 도메인·기능으로 연 오버레이. 플레이어가 눌렀을 때만 열린다(스포일러 방지).
- **도움말**: 지금의 긴 "처음 해 보는 단계" 팝업 내용을 여기로 옮긴다. 처음에는 말풍선 한 줄만 보여 준다.

## 1단계 원인 역추적 — 세 칸 배치

```
┌──────────────┬──────────────────────────────────┬───────────────┐
│ ① 사건·증거   │ ② 신호 경로 (도미노)               │ ③ 가설·영향     │
│ 폴라로이드 3장 │  센서 → 제어기 → CAN → 부품 → 차량   │ 가설 카드 세로  │
│ - 주행 사진   │  [?]──[?]──[처음 어긋남]──[✗]──[✗]  │  판단 보류/반박 │
│ - 계측 사진   │  아래: 지금 도미노의 후보 3장(측정)   │ 영향 범위(회귀) │
│ - 경고등      │  시간축(먼저/나중)                   │               │
└──────────────┴──────────────────────────────────┴───────────────┘
```
- 너비 비율 1 : 2.4 : 1. 가운데가 주 조작 공간.
- 흐름: 왼쪽 사진에서 증상 확인 → 가운데에서 거꾸로 측정·연결 → 측정할 때마다 오른쪽 가설 카드가 반박됨/판단 보류로 바뀐다.
- 끝: "처음 어긋난 곳"과 의심 구간을 정한다. 원인은 확정하지 않는다. 판단 보류 가설 2개 이상을 들고 다음 단계로 간다.
- 촉감:
  - 폴라로이드: 들면 살짝 커지고 기울며, 놓으면 자석처럼 붙는다.
  - 측정: 카드 뒤집기와 짧은 종이 소리.

## 2단계 요구사항 기반 로직 퍼즐 — 판 크게, 설명 작게

```
┌────────────────────────────────────────────────┬───────────────┐
│ 퍼즐판 (화면 70%)                                │ 요구사항 카드   │
│  [센서]→[필터]→[ ? ]→[맵]→[ ? ]→[출력]            │  REQ-1 …       │
│        블록 끌어 끼우기 · 연결되면 신호 점이 흐름   │  REQ-2 …       │
│                                                  │ (입력 범위·단위·│
│ 남은 조각 칸                                      │  보간 규칙 명시)│
├────────────────────────────────────────────────┴───────────────┤
│ 예시 입력 슬라이더(페달 0~100%) → 칸마다 값 미리보기   [연결 확인] │
└────────────────────────────────────────────────────────────────┘
```
- **연결 확인과 요구사항 검증을 분리한다.**
  - "연결 확인"은 조각 모양과 신호 종류만 본다(초록 테두리).
  - 요구사항을 만족하는지는 판정하지 않는다. 그 판정은 3단계 몫이다.
- 예시 입력 슬라이더로 값이 칸마다 어떻게 바뀌는지 탐색할 수 있다. 정답 표시는 하지 않는다.
- 완료하면 "이 로직이 검증 단계의 기대값(정상 기준)이 됩니다" 한 줄을 띄우고, 완성된 판이 3단계 왼쪽 로직 보기로 그대로 넘어간다.
- 요구사항 문장은 수치 근거를 적는다. 예: "페달 0~100% → 토크 요청 0~340 Nm 선형(교육용 단순화), 가용 토크 한계 260 Nm".
- 조각은 지금보다 크게 한다(최소 120px). 끼울 때 눌림·복원 연출과 스냅음을 넣는다.

## 3단계 시뮬레이션 검증 — 가설에서 시작

```
┌──────────────────────────────────────────────────────────────────┐
│ 시험 계획 카드: [무엇을 확인? 가설] → [어느 경계? 레벨] → [입력] → [시험]│
├───────────────────────────────────┬──────────────────────────────┤
│ 왼쪽 시각화 (가설·레벨에 맞는 것 하나)   │ 신호 모니터                    │
│  - 로직 블록도 (퍼즐에서 만든 판)       │  꽂은 관측점이 위로             │
│  - ECU·배선 3D 실험대                 │  기준 점선 vs 결과 실선          │
│  - 실부품(팬·유압·모터) 3D            │  PASS / FAIL / 판단 불가        │
│  - 차량 주행 보기                     │  [시험 실행]                    │
└───────────────────────────────────┴──────────────────────────────┘
```
- **첫 질문을 레벨이 아니라 "어느 가설을 확인할까요?"로 바꾼다.**
  - 판단 보류 가설 중 하나를 고르면, 그 가설을 가를 수 있는 레벨이 표시된다.
  - 다른 레벨도 고를 수 있다. 고르면 결과로 "이 레벨에서는 판단 불가"를 배운다.
- 결과 판정은 두 층으로 보여 준다.
  - 시험 판정: PASS / FAIL / 판단 불가.
  - 가설 판정: 지지됨 / 반박됨 / 추가 증거 필요.
- 원인 확정: 참 가설이 지지되고 나머지가 모두 반박되면 확정한다(이미 구현).
- 왼쪽 시각화는 가설에 따라 하나만 띄운다. 예: 열관리 "팬 모터" 가설이면 실부품 3D, 구동 "SW" 가설이면 퍼즐 블록도. 쓰지 않는 것은 숨긴다.

## 작업 순서와 범위 (승인 후)
1. 공통 가설 카드 줄 + 차고 노트 오버레이 + 도움말 이동 (세 화면 공통)
2. 1단계 세 칸 배치(기존 도미노·폴라로이드 재배치)
3. 2단계 연결 확인/요구사항 판정 분리 + 예시 입력 슬라이더 + 조각 크기·촉감
4. 3단계 "가설 먼저" 계획 카드 + 시각화 선택
5. 1280×720 · 1512×760 · 1920×1080에서 겹침·스크롤 점검, 두 사건(구동·열관리) 처음부터 끝까지 플레이

새로 만들지 않는 것: 새 화면, 새 3D 에셋, 자유형 회로 편집기.
