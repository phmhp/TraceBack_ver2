## 현재 작업
- 사용자 피드백 29항목 후속 수정 중. 최신 구현을 다시 대조한 결과, 정비소 내부 breadcrumb, 레벨 선택 사건 그래픽, 도미노 증거 필터·단계 브리지, E/E 부품 층 채도, 공통 하단 높이 보정을 반영했다.
- 문서: `docs/FEEDBACK_2026-11-15_B.md`에 29항목 상태를 갱신했고, `docs/TERMINOLOGY_GLOSSARY_V3.md`를 추가했다. `PLAYER_FLOW_AUDIT_2026-11-15.md`의 실험대 흐름도 R21에 맞게 고쳤다.
- 브라우저에서 최신 변경을 확인한 뒤, 레이싱 코스 다양화는 `trackFrame`의 공통 경로 키프레임으로 반영했고, 출발 직후 추격 HUD·미니맵 경찰 표시는 경찰 합류 뒤에만 보이도록 했다.
- 도미노 확인 신호는 패널 안에서 말줄임·줄바꿈을 제한했고, 증거 탭은 이상 판정으로 등록한 신호만 보인다. 전용 고양이 사건 이미지와 C04/C06 증거 이미지는 사용자 에셋 승인 대기다.
- 이번 후속 수정에서 전체 보기의 파워트레인·섀시·차량 제어 역할 설명, 레벨 선택 사건 그래픽 위 고양이 오버레이, 검증 단계의 수리 후 재시험 잔여 문구 제거를 반영했다. 실험대는 원인 제거 확인 후 `수리 적용 · 주행 복귀` 한 경로만 남긴다.
- 추가 반영: 정비소·레벨 선택에서 추격 격차를 숨기고, 레벨 선택 호버 이동을 제거했다. 전체 보기에는 협조 제어 신호 카드를 추가했으며, 도미노 신호 탭은 역추적 경로만, 증거 폴라로이드는 이상 판정 이유를 하단 캡션으로 보인다. 공통 하단 영역은 220px로 확장하고 다음 버튼 높이·패딩과 도장형 결과 문구를 통일했다. 레이싱은 정상 사건의 주행 구간을 늘리고 해안 코스를 굴곡형 키프레임으로 다양화했다.
- 정비소 첫 진입은 텍스트형 논리 카드 대신 배선 없는 3D 영역 조합을 기본으로 보여준다. `겹쳐 보기`에서만 배선이 나타나고, `아키텍처`를 누르면 역할·입출력·협조 신호를 그래픽 카드로 확인할 수 있다.
- 추가 보정: 레이싱 시작 직후 `gap` 값만으로 뜨던 경찰 접근 상황 카드·말풍선을 경찰 합류 조건 뒤로 이동했다. 퍼즐은 미배치 선지를 중앙 보드에서 제거하고 하단 작업 영역의 그래픽 선지 트레이로 옮겨 선택 후 빈칸에 넣도록 했다.
- 1600×900 Chrome에서 앱 재로드 후 컴파일 오류·경고가 없고 타이틀 화면이 정상 렌더링되는 것을 확인했다. 3D 쇼룸도 직접 진입해 브라우저 오류가 없음을 확인했다.
- 최신 화면 점검에서 개발자 메뉴로 도미노 화면에 진입할 때 `EeTraceV2`의 단계 브리지에 정의되지 않은 `found` 변수가 있어 렌더링이 중단되는 문제를 발견했다. `found = phase === "hyp"`로 V2 상태에 맞게 복구했고, 개발자 점프 후 도미노 화면이 정상 표시되는 것을 확인했다.
- 레벨 선택 화면은 어두운 실험실 톤을 낮추고 밝은 하늘·잔디·흙길·마을형 레벨 마커·따뜻한 카드·초록 시작 버튼으로 재조정했다. 1600×900에서 레벨 노드·우측 사건 카드·하단 안내/시작 영역의 겹침과 잘림이 없는 것을 확인했다.
- 개발자 메뉴 토글은 클릭 영역을 54×22px로 키우고 패널이 토글을 가리지 않도록 위치를 보정했다. 현재 브라우저에서 레벨 선택 → 개발자 메뉴 → 도미노 점프를 확인했다. 실험대는 시험 카드·문서 팝업 버튼·검증 선택지·하단 단계 이동을 함께 점검했다.
- 이번 모델링/UI 재확인에서 정비소 전체보기의 최초 모드를 `겹쳐 보기`로 바꾸고, 공용 `SignalCable` 기본 경로를 부품 아래 수직 하강 → 수평 구간 → 목적 포트 상승의 정돈된 경로로 바꿨다. 도미노 영향/가설 방향키는 `↑/↓`로 통일했고, 단계 브리지는 독립 행으로 분리했다. 퍼즐 하단 조각은 그래픽 영역을 키웠고 검증 진입 카드는 밝은 비교 카드로 정리했다.
- 정비소 실제 체인에서 휠·차체가 포함된 기능은 차량 문맥용 휠·차체를 중복 렌더링하지 않도록 했다. 제동 ECU·유압 모듈레이터와 열관리 ECU·펌프·밸브·팬·라디에이터의 좌표·회전·축척을 분리해 같은 위치에 포개지지 않게 보정했다. 이 변경은 화면에서 도메인별로 다시 확인해야 한다.
- 위 보정을 재검수하면서 기존 임의 좌표계와 기능별 자동 중앙정렬이 차량 플랫폼 기준을 깨는 것을 확인해 수정했다. 정비소 `VehicleLayout`을 주행차량과 같은 `X/Y/Z` 축·차축·휠 중심으로 통일하고, 차체 문맥은 공용 `carBody` 형상을 사용하며, 각 부품은 `PLACE.target` 외곽 크기로 스케일한다. 구동·제동·열관리·조향 화면에서 재렌더링해 위치 이동·차체/휠 중복·주요 부품 포개짐을 확인했다.
