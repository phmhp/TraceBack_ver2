# 레벨형 진행과 정비소 학습 연결 (설계 제안, 승인 대기)

화면 구조가 바뀌므로 승인 후 구현합니다(`DESIGN_DECISIONS_V3.md` 2절 규칙).

## 1. 현재 진행
타이틀 → 새 게임 시작 → 프롤로그 → 정비소(학습) → 주행(고장 발생) → STEP02 → STEP03 → STEP04 → 수리 → 다음 사건(필수 구동·열관리, 선택 제동) → 해적선 엔딩. 사건 순서는 고정이지만 사건 선택·진행 상황이 보이지 않습니다.

## 2. 제안: 레벨형 진행
### 2.1 흐름
`타이틀 → 새 게임/이어하기 → 레벨 선택 화면(월드맵) → [레벨 시작 브리핑 → 정비소 → 주행 → STEP02~04 → 수리·결과] → 레벨 선택 화면 …→ 모든 필수 레벨 클리어 시 엔딩 해금`
- 고장은 랜덤이 아니라 **레벨마다 정해진 사건**입니다. 레벨 순서는 난이도 곡선을 따릅니다(쉬운 증상·단일 입력 → 상태·시점이 복잡한 사건).
- 한 레벨 = 사건 1개 + 연결된 정비소 복습 + 주행 시나리오. 소요 약 5~8분.
### 2.2 레벨 선택 화면 (새 화면)
- 지도 위에 레벨 노드가 길로 이어짐. 상태: 잠김 / 도전 가능 / 클리어(별 1~3). 다음 레벨은 앞 레벨을 클리어하면 열림.
- 노드를 누르면 오른쪽 360px 패널에 **레벨 카드**: 이름, 도메인 아이콘, 증상 한 줄, 시점 아이콘(시동 전·정차·주행·제동 등), 난이도, 이번에 배우는 검증 개념 한 줄, 관련 정비소 기능, 최고 별. "시작" 버튼은 우측 아래(다른 단계의 다음 버튼 자리).
- 상단에 진행 요약(클리어 n/전체, 도메인 숙련도 막대), 왼쪽 위 "정비소 도감" 진입.
- 규격: 1600×900 캔버스, 우측 패널 360px, MISSION 바 없음(대신 타이틀 줄). 기존 UI 톤(핑크~갈색, 글라스) 유지.
### 2.3 구조
- 레벨 정의 데이터 `LEVELS: { id, caseId, order, unlock, chapter, title, teaser, tags(domain, phase, difficulty) }`를 한 파일에 두고 사건 시트의 개요와 같은 값을 씁니다.
- 스토리: 챕터(스토리 구간) 단위로 레벨을 묶고, 챕터 클리어가 엔딩 조건. 현재 필수 사건(구동·열관리)은 챕터 1, 선택 사건은 보너스로 이동.
- 저장: 레벨별 클리어·별·최고 기록을 저장 키에 추가(저장 버전 키 필요).
- 후속(여건 되면): 레벨마다 다른 맵·환경(노면, 온도, 경사)과 트리거 연동.

## 3. 정비소 학습 연결 (사건을 풀면서 도메인 원리도 공부)
정비소 4층 데이터는 이미 양질이므로 사건 흐름 곳곳에서 다시 꺼내 보게 합니다. 부담을 늘리지 않도록 **선택 열람 중심**으로 설계합니다.
| 방법 | 설명 | 비용 |
|---|---|---|
| A. 오픈북 확장 | 지금은 사건당 1~2장. 사건의 관련 기능 4층(기능 흐름·부품·SW 구성·SW 로직) 요약을 탭으로 제공 | 낮음 |
| B. 노드 "원리 보기" | STEP02 판의 노드를 길게 누르면 해당 부품/신호가 정비소에서 어떤 역할인지 카드 한 장 | 중간 |
| C. 퍼즐 블록 연결 | STEP03 블록의 "정비소에서 본 곳"을 눌러 해당 정비소 층을 팝업으로 열기(이미 문구는 있음) | 낮음 |
| D. 결과 화면 "배운 원리" | 사건 클리어 때 이번에 쓴 원리 3줄과 정비소 기능 번호를 보여 주고 "정비소 도감"에 카드로 수집 | 중간 |
| E. 정비소 도감·숙련도 | 정비소에서 본 기능·사건에서 쓴 기능을 카드로 모아 도메인별 숙련도 막대. 레벨 카드에 "필요한 정비소 기능" 표시, 선택적으로 미열람 기능은 브리핑에서 추천 | 중간 |
| F. 브리핑 퀴즈(선택) | 레벨 시작 전 정비소 기능 1개를 짧게 확인(버튼 선택 1문항, 건너뛰기 가능) | 중간 |
- 권장: A, C, D를 먼저(낮은 비용, 효과 큼), B와 E는 레벨 화면과 함께. F는 부담이 크니 선택 사항.
- 규칙: 사건 정보는 정답을 노출하지 않는 "정상 동작" 자료만 쓴다(오픈북의 기존 원칙).

## 4. 결정 필요
1. 레벨형 진행과 레벨 선택 화면 도입 승인
2. 레벨 순서·챕터 구성(사건 시트가 쌓인 뒤 확정해도 됨)
3. 정비소 학습 연결에서 먼저 할 항목(권장: A, C, D)
