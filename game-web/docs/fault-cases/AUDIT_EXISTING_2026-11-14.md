## 수정 내용 (적용 완료)
1. **증상 카드(R1, R4):** 사건마다 "실제 증상 1 + 영향 없는 출력 2"로 바꿈. 영향 없는 출력은 기준=이번 값(예: 제동 감속 3.2 m/s², 조향 반응 100%, 노면 마찰 0.8 μ). 결과로 함께 비정상이 된 계기판·표시등은 카드에서 제외. 정답 위치는 사건마다 다름(구동 3번째, 열관리 2번째, 제동 1번째).
   - 데이터: `DominoTrace.tsx` 각 사건에 영향 없는 차량 구역 노드 추가(`decel_ok`, `steer_ok`, `accel_ok`), `EeTrace.tsx`의 `symptomChoices` 구성 변경.
2. **말투(R3):** 수리 선택지 근거 2곳, STEP04 가설 질문 8곳을 해요체로 변경(예: "~가 잘못된 거야?" → "~가 잘못된 건가요?"). 관련 테스트 문구도 갱신.
## 남은 과제 (다음 라운드)
- 세 사건 시트(`docs/fault-cases/propulsion.md` 등)를 템플릿에 맞춰 작성하고 교차 검토. 이때 R1(가설·조각·수리 선택지), R11(진단 채널), R12(확장 필드)를 채우고, 모호하거나 형식이 다른 선택지를 전수 점검.
- 제동 사건의 수리 선택지와 STEP03 남은 조각 함정의 R1 점검.
- 세 사건이 모두 순항·감속·연속 부하 시점이고 범주가 B/E에 몰린 점은 새 사건으로 보완(`FAULT_CASE_SELECTION_V3.md` 6절).
