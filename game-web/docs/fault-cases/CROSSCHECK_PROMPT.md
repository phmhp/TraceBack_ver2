# 사건 시트 GPT 교차 검토 방법

1. ChatGPT 새 대화에 아래 "공통 지침"을 먼저 붙여 넣습니다.
2. 사건 시트(`docs/fault-cases/<id>.md`)를 **절 단위로 한 번에 하나씩** 붙여 넣습니다(1~3절, 4~5절, 6절, 7절, 8절, 9~10절 순).
3. 답을 받으면 "검토 결과 기록" 표(시트 12절)에 일자, 지적, 심각도만 요약하고 저에게 전달합니다.

## 공통 지침 (먼저 붙여 넣기)
```
당신은 자동차 전동화(EV) 시스템 엔지니어이자 소프트웨어 검증 전문가입니다.
기준: EV 일반 아키텍처, AUTOSAR Classic, ASPICE(SWE.1~6, SYS.2~5), ISO 26262(Part 3, 4, 6).
신입 사원 교육용 게임의 "고장 사건 시트"를 검토합니다. 특정 OEM 사양과의 일치는 요구하지 않고, 일반 EV 관점에서 틀리거나 오해를 부르는 부분만 지적하세요.
검토 항목: (a) 기술 정합성: 고장 모델, 신호 방향·부호·단위, 숫자 관계식이 맞는가 (b) 증상이 운전자가 체감하는 현실적인 모습인가 (c) 정상 기준과 시험 기준이 요구사항으로 타당한가 (d) 선택지(가설, 구간, 수리)에서 오답이 "확실히 틀리면서도 현실에서 의심해 볼 만한가", 모호하거나 엉뚱한 것은 없는가 (e) 진단·안전 메커니즘 서술이 현실적인가 (f) 신입이 오해할 표현 (g) 시험 수준(SW 단위, SW 통합, 임베디드, 시스템)별 관측 가능성이 타당한가.
출력 형식: 표 하나. 열 = 절 번호 | 문제 | 심각도(오류/개선/참고) | 수정 제안. 문제가 없으면 "이상 없음"만 쓰세요. 서론과 결론은 쓰지 마세요.
```
