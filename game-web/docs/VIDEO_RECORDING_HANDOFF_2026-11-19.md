# TraceBack 홍보영상 재녹화 인수인계

작성일: 2026-11-19
브랜치: `contest/v4`

## 목적

현재 홍보영상의 전체 구성과 컬러감은 유지하고, 실제 게임 화면을 다시 조작하면서 바뀐 UI를 녹화한다. 스틸컷을 순서대로 보여주는 슬라이드 영상으로 대체하지 않는다.

현재 사이트에는 기존 영상이 그대로 배포되어 있다. 녹화 결과를 확인·승인하기 전에는 사이트 파일을 교체하거나 재배포하지 않는다.

## 유지할 것

- 기존 영상의 전체 흐름, 컬러감, 전환 분위기
- 실제 게임 화면과 마우스 커서가 움직이는 조작 과정
- 기존 썸네일: `game-web/promotion/assets/cutscene-ship-jump-v1.png`
- 영상의 기본 규격: 1920×1080, H.264 MP4, 가능하면 30fps
- 영상 섹션의 현재 랜딩 레이아웃과 본문 텍스트

## 다시 녹화할 것

1. 영상 첫 부분의 로고/타이틀 화면
   - `TraceBack`과 상단 문구가 붙지 않도록 충분한 세로 여백을 둔다.
   - 기존 영상과 같은 어두운 배경·주황/노랑 계열 컬러를 유지한다.
2. 실제 게임 플레이 중 UI가 변경된 구간
   - 마우스 커서가 실제 버튼·탭·단계를 따라 이동하는 모습이 보여야 한다.
   - 정비소 → 레이싱 → 도미노 → 퍼즐 → 실험대의 흐름이 자연스럽게 이어지도록 한다.
3. 영상 마지막의 로고/마무리 화면
   - 기존 엔딩의 속도감과 컬러감을 유지한다.

## 녹화 권장 방법 — Windows

OBS Studio를 권장한다. Windows Xbox Game Bar도 가능하지만, 커서·오디오·구간 편집을 확인하기 어렵다.

### OBS 기본 설정

- 캔버스/출력 해상도: 1920×1080
- FPS: 30
- 형식: MKV로 먼저 녹화 후 OBS에서 MP4로 remux
- 소스: 게임 캡처 또는 브라우저 창 캡처
- 마우스 커서 캡처: 켜기
- 브라우저 확대율: 100%
- 녹화 중 알림, 주소창, 개발자 도구, 다른 창은 보이지 않게 한다.

### 녹화 순서

1. 공개 게임 페이지를 연다: `https://traceback-game-promo.exactsunbird8.chatgpt.site/?embed=1`
2. 브라우저 창을 1920×1080 녹화 영역에 맞춘다.
3. 시작 화면에서 타이틀이 충분히 보이도록 2~3초 정지한다.
4. 기존 영상처럼 마우스로 실제 UI를 천천히 선택한다.
5. 정비소·레이싱·도미노·퍼즐·실험대의 핵심 조작을 녹화한다.
6. 마지막 결과/로고 화면도 2~3초 유지한다.
7. 녹화 파일을 우선 MKV로 저장한 뒤 OBS의 `파일 → 녹화 다시 다중화(Remux)`로 MP4를 만든다.

최종 승인된 MP4만 아래 파일명으로 교체한다.

## 확인 체크리스트

- [ ] 스틸컷 슬라이드 영상이 아니라 실제 게임 조작 녹화인가
- [ ] 마우스 커서가 보이고 조작 위치를 따라가는가
- [ ] 첫 타이틀의 `TraceBack`과 상단 문구 사이 간격이 충분한가
- [ ] 기존 영상과 컬러감·속도감·전환 분위기가 유지되는가
- [ ] 변경된 UI가 실제 화면에 반영되어 있는가
- [ ] 마지막 로고/마무리 화면이 자연스러운가
- [ ] 1920×1080, H.264 MP4로 재생되는가
- [ ] 영상 첫 프레임·중간·끝 프레임을 별도로 확인했는가
- [ ] 사용자의 최종 확인 전에는 배포하지 않았는가
