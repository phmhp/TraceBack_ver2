# 레이싱 개편 아이디어 (설계 제안, 구현 전)

전제: 현실 세계와 같은 환경만 쓴다. 아이템전·부스터 같은 비현실 요소는 쓰지 않는다. 고양이는 다치지 않는다(차는 찌그러질 수 있음, 게임상 허용된 전제).

## 1. 목표
1. 레이싱 길이를 늘린다(레벨형 진행과 연결: 레벨마다 코스 구간).
2. 현실에서 일어나는 도로 상황을 다양하게 넣어, 차량이 이미 갖춘 안전·제어 로직(정상 동작)을 체험하게 한다. 그래야 "정상 동작"과 "고장"의 차이가 학습으로 남는다.
3. 고장 발생을 고정된 모양에서 풀어 시동 전, 정차, 갑작스런 정지, 트리거 없음 등 다양하게 만든다(`FAULT_CASE_SELECTION_V3.md` 4절).
4. 엔딩 품질을 높이고 고양이 얼굴(표정) 연출을 넣는다.

## 2. 현실 도로 상황 목록 (게임 요소 후보)
| 분류 | 요소 | 차량이 보여 줄 정상 동작(학습 연결) |
|---|---|---|
| 교통 신호 | 신호등(빨강·노랑·초록), 정지선 | 감속, 정차, 정차 중 시동 유지(전원), 출발 시 토크 응답 |
| 보행 | 횡단보도, 보행자, 어린이 보호구역 | 제한 속도 준수, 급제동 때 ABS·회생 협조, 자동 긴급 제동(AEB) |
| 동적 장애물 | 앞차 급제동, 끼어들기, 이륜차, 동물 | 거리 유지·감속 요청(운전자 지원), 급제동 |
| 정적 장애물 | 낙하물, 공사 구간 콘, 정차 차량, 맨홀 | 회피 조향(EPS), 현가 충격 흡수 |
| 도로 형상 | 터널, 내리막·오르막, 급커브, 과속방지턱 | 회생, 열 부하, 차고·댐퍼, 조향 보조 |
| 환경 | 비·젖은 노면, 안개, 야간, 저온 | ABS 개입, 시야, 배터리 출력 제한(저온) |
| 충돌 | 정면·측면 충돌, 추돌, **뒷차가 추돌** | 충돌 신호 → 에어백 전개, 고전압 차단(HV cut), 위험 경고등, 시동 꺼짐. 이는 **정상 동작**이며 고장과 구분해 학습 |
| 추락·전복 위험 | 난간 이탈, 경사 이탈 | 같은 충돌 대응. 고양이는 무사(연출: 착지), 차는 파손 |
| 비정상 상황 | 긴급차량 양보, 검문, 도로 폐쇄 | 정차·재출발 |
| EV 특유 | 배터리 잔량(SOC)·주행 가능 거리, 충전 정차 | 전력 예산, 충전 도메인과 연결 |
## 3. 레벨과 코스의 연결
- 레벨마다 코스 구간과 상황 구성을 고정한다. 레벨 선택 카드에 "시점 아이콘(시동 전·정차·주행·제동)"과 "주요 상황(신호등, 보행자, 터널 등)"을 표시.
- 같은 고장도 상황이 다르면 다르게 느껴진다(예: 신호 대기 중 시동 꺼짐 vs 고속 주행 중 출력 저하).
- 길이: 레벨당 코스 약 3~5분 주행 + 사건 조사. 지금 약 1.2 km 한 코스를 레벨별 구간으로 나누거나 새 맵을 추가한다.
## 4. 고장 스케줄 일반화 (구현 시 필요)
- 고장 정의를 `{ 시점(phase), 조건(조작·속도·시간·환경·이벤트), 지연/확률, 지속성(영구·래치·간헐), 연출 }`로 데이터화.
- 시동 전 단계(출발 대기, READY 불가), 정차 중, 갑작스런 시동 꺼짐(계기판 정전), 트리거 없음(처음부터)의 연출을 단계적으로 구현. 1차: 시동 전과 정차 중.
## 5. 게임성 요소 (현실 기반만)
- **안전 운전 점수:** 법규 준수(신호·제한 속도·보행자 양보), 부드러운 가속·제동, 회생 활용(에코 점수). 위반하면 점수 감점이지 비현실적 벌칙은 아님.
- **추격 긴장:** 경찰차와의 거리(이미 있음). 검문·도로 폐쇄 같은 현실적 장애로 우회 선택.
- **과제(미션):** "신호 한 번도 안 놓치고 구간 통과", "보행자 양보", 레벨 별과 연결.
- **리플레이 요소:** 레벨별 별 3개(클리어, 원인 정확, 안전 운전).
- 금지: 부스터, 아이템, 점프대 등 비현실 요소.
## 6. 고양이 연출
- 충돌·정차 시 고양이 반응(놀람, 아찔함, 안도)을 얼굴 표정으로 표현. 다치는 표현은 하지 않음(전제).
- 이미지 필요: 고양이 표정 세트(볼트·너트 각 4~5종: 평온, 집중, 놀람, 안도, 기쁨, 실망). **한 번에 한 장** 규칙으로 프롬프트 작성 예정.
## 7. 엔딩 개편
- 성공: 레벨 별 합계에 따라 고양이 표정과 짧은 후일담(별 개수별). 해적선 승선 컷. (구현됨 2026-11-14: `endingMoods.ts`, 표정 이미지는 사용자 제작 대기)
- 실패(CAUGHT): 같은 형식, 표정만 다르게(고양이는 무사).
- 결과 화면에 "배운 원리 카드 모음"과 정비소 도감 요약.
## 8. 결정 필요
1. 코스를 레벨별로 나눌지(구간 재사용), 새 맵을 만들지
2. 1차 현실 상황 세트(예: 신호등+횡단보도+보행자 / 앞차 급제동 / 터널 / 뒷차 추돌) 우선순위
3. 충돌 대응(에어백·HV 차단·시동 꺼짐)을 "정상 동작" 연출로 먼저 만들지
4. 안전 운전 점수와 에코 점수 도입 여부
5. 고양이 표정 에셋 제작 일정(사용자 제작)

## 9. 추가 요구 (2026-11-14): 충돌 액션, 고장↔추격 연동, 추리 중 시간 지연
### 9.1 현재 상태 (코드 확인)
- 일반 차량 7대가 정해진 일정(레이스 시계)으로 이동하고 차선을 유지합니다. 부딪히면 내 차 속도가 약 35% 줄고 상대는 0.7초 머뭇거릴 뿐, 시각적 충돌 연출(차체 변형, 파편, 카메라 반응)은 거의 없어 **보호막처럼** 느껴집니다. 상대가 비켜 가는 것처럼 보이는 것도 일정 기반 이동 때문입니다.
- 추격차는 `이전 간격 + (내 속도 − 경찰 속도 68~88 km/h) × 시간`으로 변하고, 추리·검증 중에는 초당 0.2 m만 줄어듭니다(사실상 시간이 느리게 흐르는 상태이지만 플레이어에게 보이지 않음).
### 9.2 충돌 액션 강화 (제안)
| 항목 | 내용 |
|---|---|
| 충돌 종류 | 스침 / 측면 / 추돌(가해) / 추돌(피해, 뒷차) / 정면 / 가드레일·난간 |
| 충격 단계 | 상대 속도·각도로 경미 / 중간 / 강함 계산 |
| 시각·청각 | 차체만 흔들리는 충격 연출(카메라·세상은 고정)과 화면 번쩍임, 파편, 차체 찌그러짐(단계별 변형·떨어지는 부품), 충돌음, 상대 차 회전·밀림·정지, 고양이 표정 반응(놀람) |
| 차량 반응(정상 동작) | 강함: 에어백, 고전압 차단, 위험 경고등, 시동 꺼짐 → 재시동(R) 시도. 경미: 속도 손실과 반발 |
| 교통 | 정체·급제동·끼어들기·정차 차량을 추가해 부딪히기 쉬운 환경 구성, 상대가 일정대로만 비켜 가지 않음 |
| 게임 영향 | 충돌은 속도 손실, 정지 시간, 추격차 급감으로 이어짐. 안전 운전 점수 감점 |
| 고양이 | 다치지 않음(연출: 착지, 놀란 표정), 차는 파손 |
### 9.3 고장↔추격 연동표
추격차 변화율 = (내 속도 − 경찰 속도) × 시간 (경찰 약 70~90 km/h, 접근할수록 빨라짐). 고장이 내 속도·방향·조작을 바꾸면 추격차도 자연히 달라집니다.
| 고장의 영향 | 플레이어 상황 | 추격차 | 게임적 선택지 |
|---|---|---|---|
| 정지(시동 불가·꺼짐·구동 불가) | 움직일 수 없음 | 경찰이 일정 속도로 접근 | 빨리 원인을 찾아 재출발 |
| 출력 제한(열·배터리) | 속도 상한(예: 55 km/h) | 경찰 속도가 더 빠르면 서서히 접근 | 회생·열 관리, 구간 선택 |
| 후진만 가능(변속 인터록 고장) | 전진 불가 | **후진 방향은 경찰 쪽** → 가까워짐 | 급히 방향을 바꿔 후진으로 도주(후방 카메라 시야, 속도 상한 낮음) |
| 제동 약화 | 감속 불가 | 속도는 유지되지만 충돌 위험 | 엔진브레이크(회생 최대), 접촉 최소화 |
| 급가속·가속 제어 불가(N01) | 조향만 가능, 마찰 제동으로 정지 가능 | 벌어지다 충돌하면 급감 | 충돌 회피, 제동으로 속도 조절 |
| 조향 불가·무거움 | 직진 위주 | 구불길에서 접근 | 직선 구간 활용 |
| 간헐 고장 | 구간별로 정상·비정상 반복 | 변동 | 재현 조건 학습 |
### 9.4 추리 중 시간 지연 ("추리 시간 감속")
- 컨셉: 고장 난 순간 차가 멈춰 있는 동안 세계의 시간이 느리게 흐른다(영화처럼 다른 시간대의 행성). 플레이어가 STEP02~04를 충분히 생각할 수 있도록 **시간 배율**을 정해 둔다. 현재 값은 사실상 1/30 수준(경찰 약 6.7 m/s ↔ 0.2 m/s).
- 플레이어에게 보이게 한다: 상단바 추격차 HUD 옆에 "추리 중 · 시간 1/30" 배지, 경찰차가 느리게 다가오는 연출, 화면 가장자리 슬로 효과.
- 레벨 난이도에 따라 배율 조정(쉬움 1/50, 보통 1/30, 어려움 1/15). 힌트·시험 실행은 추격차 감소로 환산(이미 힌트는 −5 m).
- 후진 도주처럼 "움직이는 고장" 사건은 시간 배율을 낮추지 않고 레이싱 중에 조사하는 방식이 될 수 있어, 사건 시트에 "추리 중 차가 정지 상태인가"를 적는다.
### 9.5 레이싱 1차 범위 (제안)
1. 고장 스케줄 일반화 + 첫 3종 연출: 조작 해제 순간(N01), 정차 중, 시동 전
2. 충돌 시스템 강화(9.2) 중 시각·청각 연출과 충격 단계, 교통 밀도·정체 구성
3. 고장↔추격 연동(9.3) 구현 틀 + 시간 지연 배지(9.4)
4. 현실 상황 세트 1: 신호등+횡단보도+보행자, 앞차 급제동, 뒷차 추돌 대응
5. 점수(안전·에코)와 터널·날씨는 2차
