# 레이싱 개편 아이디어 (설계 제안, 구현 전)

전제: 현실 세계와 같은 환경만 쓴다. 아이템전·부스터 같은 비현실 요소는 쓰지 않는다. 고양이는 다치지 않는다(차는 찌그러질 수 있음, 게임상 허용된 전제).

## 1. 목표
1. 레이싱 길이를 늘린다(레벨형 진행과 연결: 레벨마다 코스 구간).
2. 현실에서 일어나는 도로 상황을 다양하게 넣어, 차량이 이미 갖춘 안전·제어 로직(정상 동작)을 체험하게 한다. 그래야 "정상 동작"과 "고장"의 차이가 학습으로 남는다.
3. 고장 발생을 고정된 모양에서 풀어 시동 전, 정차, 갑작스런 정지, 트리거 없음 등 다양하게 만든다(`FAULT_CASE_SELECTION_V3.md` 4절).
4. 엔딩 품질을 높이고 고양이 얼굴(표정) 연출을 넣는다.

## 2. 현실 도로 상황 목록 (게임 요소 후보)
| 분류 | 요소 | 차량이 보여 줄 정상 동작(학습 연결) |
|---|---|---|
| 교통 신호 | 신호등(빨강·노랑·초록), 정지선 | 감속, 정차, 정차 중 시동 유지(전원), 출발 시 토크 응답 |
| 보행 | 횡단보도, 보행자, 어린이 보호구역 | 제한 속도 준수, 급제동 때 ABS·회생 협조, 자동 긴급 제동(AEB) |
| 동적 장애물 | 앞차 급제동, 끼어들기, 이륜차, 동물 | 거리 유지·감속 요청(운전자 지원), 급제동 |
| 정적 장애물 | 낙하물, 공사 구간 콘, 정차 차량, 맨홀 | 회피 조향(EPS), 현가 충격 흡수 |
| 도로 형상 | 터널, 내리막·오르막, 급커브, 과속방지턱 | 회생, 열 부하, 차고·댐퍼, 조향 보조 |
| 환경 | 비·젖은 노면, 안개, 야간, 저온 | ABS 개입, 시야, 배터리 출력 제한(저온) |
| 충돌 | 정면·측면 충돌, 추돌, **뒷차가 추돌** | 충돌 신호 → 에어백 전개, 고전압 차단(HV cut), 위험 경고등, 시동 꺼짐. 이는 **정상 동작**이며 고장과 구분해 학습 |
| 추락·전복 위험 | 난간 이탈, 경사 이탈 | 같은 충돌 대응. 고양이는 무사(연출: 착지), 차는 파손 |
| 비정상 상황 | 긴급차량 양보, 검문, 도로 폐쇄 | 정차·재출발 |
| EV 특유 | 배터리 잔량(SOC)·주행 가능 거리, 충전 정차 | 전력 예산, 충전 도메인과 연결 |
## 3. 레벨과 코스의 연결
- 레벨마다 코스 구간과 상황 구성을 고정한다. 레벨 선택 카드에 "시점 아이콘(시동 전·정차·주행·제동)"과 "주요 상황(신호등, 보행자, 터널 등)"을 표시.
- 같은 고장도 상황이 다르면 다르게 느껴진다(예: 신호 대기 중 시동 꺼짐 vs 고속 주행 중 출력 저하).
- 길이: 레벨당 코스 약 3~5분 주행 + 사건 조사. 지금 약 1.2 km 한 코스를 레벨별 구간으로 나누거나 새 맵을 추가한다.
## 4. 고장 스케줄 일반화 (구현 시 필요)
- 고장 정의를 `{ 시점(phase), 조건(조작·속도·시간·환경·이벤트), 지연/확률, 지속성(영구·래치·간헐), 연출 }`로 데이터화.
- 시동 전 단계(출발 대기, READY 불가), 정차 중, 갑작스런 시동 꺼짐(계기판 정전), 트리거 없음(처음부터)의 연출을 단계적으로 구현. 1차: 시동 전과 정차 중.
## 5. 게임성 요소 (현실 기반만)
- **안전 운전 점수:** 법규 준수(신호·제한 속도·보행자 양보), 부드러운 가속·제동, 회생 활용(에코 점수). 위반하면 점수 감점이지 비현실적 벌칙은 아님.
- **추격 긴장:** 경찰차와의 거리(이미 있음). 검문·도로 폐쇄 같은 현실적 장애로 우회 선택.
- **과제(미션):** "신호 한 번도 안 놓치고 구간 통과", "보행자 양보", 레벨 별과 연결.
- **리플레이 요소:** 레벨별 별 3개(클리어, 원인 정확, 안전 운전).
- 금지: 부스터, 아이템, 점프대 등 비현실 요소.
## 6. 고양이 연출
- 충돌·정차 시 고양이 반응(놀람, 아찔함, 안도)을 얼굴 표정으로 표현. 다치는 표현은 하지 않음(전제).
- 이미지 필요: 고양이 표정 세트(볼트·너트 각 4~5종: 평온, 집중, 놀람, 안도, 기쁨, 실망). **한 번에 한 장** 규칙으로 프롬프트 작성 예정.
## 7. 엔딩 개편
- 성공: 레벨 별 합계에 따라 고양이 표정과 짧은 후일담(별 개수별). 해적선 승선 컷.
- 실패(CAUGHT): 같은 형식, 표정만 다르게(고양이는 무사).
- 결과 화면에 "배운 원리 카드 모음"과 정비소 도감 요약.
## 8. 결정 필요
1. 코스를 레벨별로 나눌지(구간 재사용), 새 맵을 만들지
2. 1차 현실 상황 세트(예: 신호등+횡단보도+보행자 / 앞차 급제동 / 터널 / 뒷차 추돌) 우선순위
3. 충돌 대응(에어백·HV 차단·시동 꺼짐)을 "정상 동작" 연출로 먼저 만들지
4. 안전 운전 점수와 에코 점수 도입 여부
5. 고양이 표정 에셋 제작 일정(사용자 제작)
