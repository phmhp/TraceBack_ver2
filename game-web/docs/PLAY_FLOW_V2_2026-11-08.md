# 추리 흐름 v2 (초안) — "볼트의 질문에 증거로 답한다"

## 바꾸는 이유
- 지금 흐름: 레벨 고르기 → 입력 고르기 → 관측점 꽂기 → 판정. 플레이어가 하는 일이 "작업"처럼 보인다.
- 고객사 대응이라는 목적이 화면에 안 보인다.

## 핵심 아이디어
**3단계는 볼트(고객)가 던지는 질문 3개에 답하는 게임이다.**
- 질문 하나 = 가설 하나를 가르는 일.
- 답하려면 시험을 하나 고르고, 결과를 근거로 답한다.

---

## 1단계 · 탐문 — "누가 먼저 이상해졌나?"
| 항목 | 내용 |
|---|---|
| 미션 | 증상에서 거꾸로, 한 칸씩 "먼저 이상해진 것"을 고른다 |
| 선택지 | 매 칸 사진 3장. 눌러서 잰다(측정 1번 = 추격 거리 조금) |
| 보이는 것 | 사진 + 기준/지금 막대 + 정상·이상 한 단어 |
| 끝 | "처음 이상해진 곳"과 **남은 용의 구간 2개** |
| 얻는 것 | 신호 경로를 거꾸로 따라가는 법, 결과(함정)와 원인 구분 |
| 넘기는 것 | 남은 2개 → 3단계의 **볼트 질문**이 된다 |

## 2단계 · 설계도 복원 — "정상이라면 어때야 하지?"
| 항목 | 내용 |
|---|---|
| 미션 | 빈칸 3개를 채워 정상 로직 완성 |
| 선택지 | 조각 5개(정답 3, 표 값이 다른 함정 1, 다른 기능 블록 1) |
| 보이는 것 | 요구사항 줄, 조각 "?"(표 값) |
| 끝 | **기대값 카드 1장**: 구동은 "페달 60% → 204 Nm", 열관리는 "65°C 넘으면 팬 1850 rpm" |
| 얻는 것 | 핵심 제어 로직(맵·MIN·램프 / 히스테리시스·PI), 3단계 판정 기준 |

## 3단계 · 시험과 답변 — "볼트의 질문에 증거로 답하기"

**한 질문의 진행 (3번 반복)**
1. **질문 카드:** 볼트가 묻는다.
2. **시험 카드 고르기 (2~3장 중 하나):** 각 카드에는 그림, 쉬운 이름, 비용이 있다. 전문 이름(레벨)은 작게 보인다.
    - 예: "SW만 PC에서 돌려 보기 (SW 단위 시험) · 비용 1"
    - 예: "실제 부품을 붙여 돌려 보기 (시스템 통합 시험) · 비용 5"
3. **잴 곳 고르기 (그림에서 2곳):** 왼쪽 시각화(탭: SW 로직 / 제어기 / 부품) 위에 측정 지점이 핀으로 표시된다. 눌러서 고른다.
4. **실행:** 결과는 기대값 카드와 나란히 "기준 / 지금" 한 쌍으로 나온다.
5. **답하기 (3지선다):** "문제 있음 / 문제 없음 / 이 시험으로는 모름". 고르면 결과가 근거로 붙는다. 틀리면 너트가 이유를 짚어 준다.

**구동 사건의 질문 3개**
| 볼트 질문 | 맞는 시험 | 결과 | 답 |
|---|---|---|---|
| ① "페달 센서 고장 아니야?" | (1단계에서 이미 답함) 페달 값 측정 | 60% 정상 | 문제 없음 |
| ② "SW가 이상한 거야, 제어기 회로가 이상한 거야?" | SW만 PC에서 돌려 보기 | SW만 돌려도 처리값이 낮음 | SW 문제 있음, 회로 문제 없음 |
| ③ "그래서 뭘 고치면 돼?" | 보고서 → 수리 요청 → 같은 시험 다시 | 기대값과 같아짐 | 보정 블록 제거 |

**열관리 사건의 질문 3개**
| 볼트 질문 | 맞는 시험 | 결과 | 답 |
|---|---|---|---|
| ① "팬 끄는 SW가 잘못된 거 아니야?" | SW만 PC에서 돌려 보기 | 요구사항대로 켜짐 | SW 문제 없음 |
| ② "그럼 배선이야, 팬이야?" | 실제 부품 붙여 돌려 보기 · 잴 곳: 팬 커넥터 + 팬 | 커넥터에 명령·전원 도착, 팬은 멈춤 | 배선 문제 없음, 팬 문제 있음 |
| ③ "그래서 뭘 고치면 돼?" | 보고서 → 팬 교체 요청 → 다시 시험 | 팬이 돔 | 팬 교체 |

- **함정 시험:** 열관리 ②에서 "SW만 돌려 보기"를 고르면 결과는 PASS다. 답은 "이 시험으로는 모름"(팬이 모델이라 안 보임). 비용이 들고 너트가 이유를 설명한다.

**마지막 · 볼트에게 브리핑 (보고서 한 장)**
- 질문 3개와 답이 근거와 함께 한 장에 정리된다. 플레이어가 고른 시험 결과로만 채워진다.
- "보고하기"를 누르면 볼트가 "좋아, 고치자!" → 수리 → 재주행(같은 조건 회귀 카드).

## 지금 화면에서 바뀌는 것
| 지금 | v2 |
|---|---|
| 미션 A·B, 레벨 4개 → 입력 → 관측점 6개 중 3개 | 질문 카드 → 시험 카드 2~3장 → 잴 곳 2곳 |
| 신호 모니터에 숫자 여러 줄 | 기준/지금 한 쌍 + 막대 + 한 단어 |
| 판정 노트(가설마다 3버튼) | 질문 하나에 답 하나 |
| 처음 갈라진 신호에 깃발 | 질문 ②의 답이 곧 범인 지목 |
| 보고서는 마지막에 자동 정리 | 같음(질문·답·근거 한 장) |

- 유지: 수치 모델, 판정 규칙(레지스트리), 왼쪽 탭, 비용 별점, 회귀.
- 신호 모니터는 "자세히 보기"로 접어 두고, 원하면 열어서 그래프를 본다.
