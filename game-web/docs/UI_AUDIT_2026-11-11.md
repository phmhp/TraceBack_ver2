# STEP01~04 UI 전수조사 (2026-11-11)

기준: Chrome(macOS 개발 서버 `localhost:5180`), 에뮬레이션 1536×960 / 1054×723. 측정은 DOM `getBoundingClientRect`(겹침·잘림·문서 스크롤)와 화면 캡처를 함께 사용했다. 사용자가 브라우저 창 크기를 바꾸면 에뮬레이션이 해제되어, 각 검수 직전에 크기를 다시 설정했다.

범위의 한계: 첨부 이미지(차고지 4종)는 이 세션에 전달되지 않아 요구 문구와 실제 화면으로 대조했다. STEP01 E/E·Control SW 전수 스윕은 1280×800(사용자가 창에서 고른 크기)에서 7개 도메인 × 3레이어 × 기능 전부를 자동 측정했고, 1536·1054는 구동·제동 도메인 중심으로 눈으로 확인했다.
