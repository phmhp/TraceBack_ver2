1. 세 추상화 관점은 비슷한 틀을 쓰지만 모드별 CSS와 콘텐츠 높이가 독립적으로 영향을 준다.
2. 차고는 OFF/조건/입력 단계가 있으나 에너지·제어·기계 흐름이 하나의 명시적 공유 모델로 분리돼 있지 않다.
3. BOARD는 최신 요구의 중앙 도미노 + 우측 증거 + 촉각 메모판 구조가 아니다.

6. 검증은 실제 수치 계산을 하지만, 시험 행동보다 시험 카드/레벨 정답 선택으로 보일 위험이 있다.
7. 여러 유효 시험 경로의 판별력·부분 유효·추가 시험 평가 모델이 없다.
8. 1054×723에서 도미노 카드 라벨 잘림과 검증 입력 조건 칩 겹침이 확인됐다.
9. 표준 설명과 교육용 게임 규칙을 구분하는 메타데이터/문서 표현 규칙이 필요하다.
