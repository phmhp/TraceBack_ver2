# 반나절 구현 계획 — 보존 호환 문서

PART C의 반나절/4~5시간 제한은 PART H-1에서 철회되었다. 이 파일은 이전 산출물 이름과 추적성을 유지하기 위한 문서이며 현재 범위나 일정을 제한하지 않는다.

- P0/P1/P2를 시간 때문에 임의 축소하지 않는다.
- 전체 구현은 [IMPLEMENTATION_PLAN_AND_COMMITS.md](./IMPLEMENTATION_PLAN_AND_COMMITS.md)를 따른다.
- 이전 P0/P1/P2 항목은 [REQUIREMENT_TRACEABILITY.md](./REQUIREMENT_TRACEABILITY.md)에서 `보존·상위 결정으로 대체` 상태로 추적한다.
- 마감 시에는 최근 전체 회귀 통과 커밋을 제출 기준으로 삼되, 미완료 요구를 삭제하지 않는다.
