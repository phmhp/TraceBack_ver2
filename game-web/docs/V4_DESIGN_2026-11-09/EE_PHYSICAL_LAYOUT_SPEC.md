# E/E 논리·물리 배치 명세

## 뷰

- 연결 논리: 센서→ECU→네트워크→액추에이터 관계.
- 겹쳐보기: 논리 노드와 물리 부품 위치를 연결.
- 실제 부품: 보닛/차량 내부의 교육용 개략 배치와 커넥터.

보기 탭은 좌측 관점 패널 상단에 두며 중앙 도면을 덮지 않는다.

## 매핑

각 노드는 `logicalNodeId`, `partId`, `portId`, `flowType`, `positionEvidence`를 가진다. `positionEvidence`는 `project_asset`, `generic_vehicle_reference`, `educational_approximation` 중 하나다.

## 포트와 배선

- `partModels.ts`의 포트 ID/좌표를 우선 사용한다.
- 선은 포트에서 시작하고 포트에서 끝난다.
- 모델 회전·스케일 변경에도 월드 좌표를 다시 계산한다.
- 미지원 부품은 중앙 연결이 아니라 명시적 임시 포트 앵커를 정의한다.
- 전력, 통신, 센서, 기계 전달을 서로 다른 스타일로 표시한다.

## 대표 경로 우선순위

첫 구현은 구동 도메인의 `가속 페달→VCU→CAN→인버터→모터→감속기→바퀴`를 기준으로 한다. 이후 동일 계약으로 열관리·제동을 확장한다.

## 표현 제한

- 특정 OEM의 실제 위치라고 주장하지 않는다.
- 근거가 없는 크기·각도·위치는 교육용 개략 배치로 분류한다.
- 사진 나열만으로 E/E 물리 뷰를 대체하지 않는다.
