# 주요 화면 와이어프레임

## STEP 01 공통 외부 프레임

```text
┌ 상단: 도메인 제목 / 진행 / 도움말 ─────────────────────────────┐
│ 관점 탭: Vehicle/System | E/E Architecture | Control Software │
├────────────────────────────────────────────────────────────────┤
│ 왼쪽 보기/단계 안내 │ 동일 크기·위치의 핵심 관점 캔버스       │
│                     │ 차량·배선·로직 중 선택 관점만 교체      │
├────────────────────────────────────────────────────────────────┤
│ OFF → READY → 기어 → 입력   [이전] [다음]                     │
└────────────────────────────────────────────────────────────────┘
```

세 관점의 외부 bounding box는 동일하다. 관점 탭 전환으로 페이지가 뛰거나 하단 버튼이 이동하지 않는다.

## STEP 02 도미노/메모판

```text
┌ 사건 / 현재 질문 / 진행 ───────────────────────────────────────┐
├────────────────────────────────────────────┬───────────────────┤
│ 중앙 도미노 인과 탐색                      │ 증거 카드(우측)   │
│ 선택 요소: 수신값·역할·발신값·정상 기준    │ 2줄 라벨/스크롤   │
├────────────────────────────────────────────┴───────────────────┤
│ 메모판: 가설 종이 + 압정 + 증거 연결 실 + 미확인 표시          │
└────────────────────────────────────────────────────────────────┘
```

## STEP 03 실험 작업대

```text
┌ 가설 / 확인 질문 / 확보 증거 ──────────────────────────────────┐
├────────────────────────────────────────────────────────────────┤
│ 목적 ─ 초기 상태 ─ 입력 행동 ─ 기대 결과 ─ 관찰 지점          │
│                 기존 블록 퍼즐 캔버스                          │
├────────────────────────────────────────────────────────────────┤
│ 단계별 블록 보관함                         계획 요약/한계       │
└────────────────────────────────────────────────────────────────┘
```

## 팝업·이전/다음 공통 안전 영역

- 팝업은 화면 가장자리에서 최소 16px, 내부 스크롤 허용.
- 이전/다음 버튼 영역은 콘텐츠와 겹치지 않는 별도 행이며 고정 높이.
- 팝업이 열리면 배경 포커스와 클릭을 차단하고 닫은 뒤 원래 트리거로 포커스를 복귀.
- 움직이는 차량/배선/실 효과는 버튼과 텍스트 위로 올라오지 않게 레이어 토큰을 사용.
- `modal > tutorial pointer > navigation > content > decoration` 순서를 공통 토큰으로 고정.
