# 검증 교육 모델

## 학습 목표

플레이어는 프로세스 이름을 외우는 대신 다음 질문에 답하는 법을 배운다.

1. 무엇을 확인하려는가?
2. 어떤 조건을 만들어야 하는가?
3. 무엇을 관찰해야 후보를 구분할 수 있는가?
4. 기대 결과와 실제 결과는 어떻게 다른가?
5. 이번 시험으로 말할 수 있는 것과 말할 수 없는 것은 무엇인가?

## 점진적 공개

| 순간 | 새 개념 | 플레이어 행동 | 즉시 피드백 |
|---|---|---|---|
| 정상 동작 체험 | 입력–조건–출력 | READY, 기어, 입력을 직접 조작 | 에너지·신호·토크 흐름 활성화 |
| 사건 관찰 | 증상과 증거 | 증거 카드를 보고 관찰값 확인 | 관련 요소만 강조 |
| 가설 형성 | 최초 편차와 원인 후보의 차이 | 후보를 메모판에 붙이고 증거 연결 | 근거 충분/부족 표시 |
| 실험 준비 | 목적·조건·기대·관찰 | 블록으로 실험 계획 구성 | 누락된 항목을 짧게 안내 |
| 실행·비교 | 정상 기준과 사건 재현 | 같은 조건으로 실행하고 그래프 비교 | 최초 관찰 편차 후보 표시 |
| 판단·재시험 | 결과와 원인 판단의 분리 | 통과/실패/판정 불가 및 가설 상태 선택 | 관찰 범위와 한계 설명 |

## 판정 모델

- 시험 결과: `PASS | FAIL | INCONCLUSIVE`
- 가설 상태: `HIGH | LOW | OPEN | NEEDS_MORE_TEST`
- 근거 수준: `DIRECT | INDIRECT | INSUFFICIENT`
- 최초 관찰 편차: 관측 가능한 지점 중 가장 이른 차이이며 근본 원인의 자동 확정이 아니다.

## 초보자 피로도 규칙

- 한 화면에서 새 핵심 개념은 하나만 소개한다.
- 현재 행동과 무관한 선택지는 잠그거나 숨긴다.
- 전문 용어는 쉬운 한글을 먼저, 표준명은 도움말에 둔다.
- 긴 설명 대신 조작 → 변화 → 한 문장 해설 순서를 사용한다.
- 실패 시 전체 초기화 대신 현재 선택만 수정하게 한다.
- 색만으로 상태를 구분하지 않고 아이콘·선 형태·텍스트를 병행한다.
- 동일 자산과 용어를 네 단계에서 반복해 기억 부담을 줄인다.

## 표준과의 관계

표준은 검증 대상·목적·추적성과 같은 근거를 제공한다. 점진적 공개, 메모판, 애니메이션, 4단계 순서, 피드백 문구는 교육 효과와 플레이 경험을 위한 TraceBack의 설계다.
