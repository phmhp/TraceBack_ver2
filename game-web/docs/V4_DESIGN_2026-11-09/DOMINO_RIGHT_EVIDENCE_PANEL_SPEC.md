# 도미노 우측 증거 패널 명세

## 3열 구조

```text
context  | domino/path workspace | evidence panel
160px    | minmax(0, 1fr)        | 250~280px
```

하단에는 메모판을 전체 폭 또는 중앙+우측 폭으로 둔다.

## 증거 패널

- 우측 고정, 자체 스크롤.
- 1054px에서도 카드 제목이 최소 두 줄 보인다.
- 말줄임표만으로 핵심 맥락을 숨기지 않는다.
- 카드 선택 시 사진, 측정값, 시간, 정상 기준을 보여준다.
- 중앙으로 드래그하거나 클릭해 메모판에 붙일 수 있다.

## 중앙 도미노

- 화살표만 따라 정답을 얻지 못한다.
- 측정 전에는 값/판정이 숨겨진다.
- 정상과 사건 값, 시간, 관찰 가능한 경계를 비교한다.
- 최초 편차는 원인 후보를 좁히지만 근본 원인을 자동 확정하지 않는다.

## 촉각 메모판

- 기존 폴라로이드, 압정, 실, 종이 질감, 효과음, 미세 흔들림을 재사용한다.
- 증거와 가설을 연결하고 반박/유력/미확인을 표시한다.
- 실제로 확인하지 않은 근거는 생성하지 않는다.

## 접근성과 QA

- 드래그 외에 클릭-배치 대안을 제공한다.
- 카드 전체 제목은 접근성 이름으로 제공한다.
- 팝업, 하단 내비, 증거 스크롤이 서로 간섭하지 않는지 검사한다.
