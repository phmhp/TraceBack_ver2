### 1.4 열관리 기술 근거·가설
- [근거] 히스테리시스(65/60 °C)의 목적(채터링 방지)은 요구사항 문장에 이미 설명되어 타당. PI의 `Kp=0.002 %/rpm`, `Ki=0.004`, 기본 듀티 60 %는 **교육용 상수**로 실차 근거 없음 [코드 `simModel.ts:71~73`].
- [가설] `tm = 70 + 2.6·(tc−70)`(코일/모터 온도가 냉각수 변화의 2.6배)는 물리 근거가 없는 교육용 결합식 — 실제 모터는 손실 발열과 냉각 열저항으로 결정. 학습 목적상 유지 가능하나 "근사 모델"로 표기 권장 [결정].

### 2.4 제동 기술 근거·가설
- [근거] 회생·마찰 협조(회생을 먼저, 부족분은 마찰)는 전기차 제동 협조의 일반 개념 [업계] — 요구사항 문장 속 "회생 먼저"는 **설계 선택**으로 요구와 설계 구분 필요(`STEP02_04` §2.1-C).
- [가설] 압력→감속 환산계수(20 bar per m/s²)의 실차 타당성은 확인하지 않음(질량·캘리퍼 사양 필요). 교육용 상수로 표기하면 충분.
- [가설] 선형 감속 가정에서 정지 시간·거리는 `t=v0/a`, `d=v0²/2a`; 실제 감속은 속도에 따라 ABS·마찰 변화 — 모델은 이를 다루지 않음.
