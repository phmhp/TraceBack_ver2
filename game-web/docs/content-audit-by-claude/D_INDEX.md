## 2. 추출 방법과 한계 (반드시 읽을 것)

- **방법**: 소스(`src/**/*.ts(x)`)를 문자 단위로 스캔해 한글(또는 UI 영문 라벨) 문자열·템플릿 리터럴·JSX 텍스트를 **그대로** 기록. 사람이 옮겨 적지 않음. 표 표기용으로만 줄바꿈→`↵`, `|`→`\|`, 백틱→`ˋ` 치환.
- **ID** = `<파일코드>-<4자리 라인>-<줄 내 순번>`. 파일코드는 `D1_INDEX.md` 표. **소스 라인이 바뀌면 ID가 바뀜** → 변경 추적은 같은 스크립트로 `_d1_rows.json`을 다시 만들어 `file+text` 기준 diff.
- **카테고리는 자동 추정**(심볼명·필드명 규칙). 오분류 가능. 사건 열은 들여쓰기·줄 내 `"propulsion"` 문자열 기반 추정(`(줄 내 분기)` 표시).
- **노출 조건은 심볼 단위**(해당 컴포넌트·상수가 렌더될 때). 줄 단위 분기(`&&`, 삼항, 상태별)는 분석하지 않음 → `[줄 단위 조건 미분석]`.
- **동적 문구**(`${…}`, JSX `{…}`)는 식을 전개하지 않고 원문 그대로(`{…}`로 축약 표기된 JSX 보간 포함) 기록. 실행 값은 실행해야 알 수 있음.
- **숫자 리터럴은 D-1 표에 없다**(문자열이 아니므로). 사건별 수치(`ref/run/t`, 계약 수치, 모델 상수)는 `D3_<사건>.md`의 소스 블록과 `simModel.ts`에서 확인.
- **도달 불가 판정**: `main.tsx`의 `App` 기준 정적 호출 그래프(주석·import 제외)로 계산. 장면 이벤트 도달성은 별도 수동 확인 2건(`FailureAnalysis`/VERIFY_FAIL, `ShipBoardingSequence`/SHIP_BOARDING)만 `장면 미도달`로 표시. brake 사건 콘텐츠는 `사건 미도달(brake)` 표시. 정적 그래프는 런타임 분기까지 보증하지 않음 `[실행 검증 필요]`.
- 이미지·음원·CSS·`public/` 데이터·`*.md` 문서 문구는 추출 대상이 아니다(코드 내 문자열만). `PartModel`의 3D 지오메트리 문구 없음.
- 추출 누락 점검: 샘플 3개 구간(레이스, STEP04, 타이틀)에서 한글 포함 코드 라인 대비 누락 라인 0~1(주석 1줄만 제외)을 확인. 전체 파일 전수 대조는 하지 않음.

4. 사건 데이터 소스 변경 시 갱신할 파일: `D3_<사건>.md`(소스 블록), `D4_TECHNICAL_REVIEW.md`(관련 ID 열).
