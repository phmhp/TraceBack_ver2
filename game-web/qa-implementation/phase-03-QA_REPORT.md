# 단계 3 Chrome QA — 도미노 역추적

## 실행 환경

- 대상: `http://127.0.0.1:5173/?qa=BOARD`
- 브라우저: 설치된 Google Chrome, 1054×723
- 사건: 대표 구동 출력 저하

## 확인 장면

- `phase-03-final-intro`: 최초 진입 안내 팝업
- `phase-03-final-before`: 문제 풀이 전 중앙 경로·우측 증거·하단 메모판
- `phase-03-final-popup`: 주행 기록 기준/실제 비교 팝업
- `phase-03-final-after`: 최초 편차·반박/보류 가설 정리 후 화면

## 상호작용·교육 검수

- 중앙 E/E 경로에서 증상 출력부터 원인 방향으로 역추적한다.
- 오른쪽 증거는 286px 독립 열과 자체 세로 스크롤을 가지며 카드 제목/설명은 최대 2줄이다.
- 하단 메모판은 관찰 사실, 최초 편차, 원인 후보를 서로 다른 압정 메모로 분리한다.
- 동일 입력 재생 후 기준값/실제값과 달라진 시각을 비교하며, 최초 편차를 곧바로 근본 원인으로 확정하지 않는다.
- 미관찰 원인을 만들어내지 않고 측정으로 반박된 가설과 아직 구분할 수 없는 가설을 분리한다.

## UI 결함과 조치

- 첫 완료 캡처에서 가설 카드가 한 열로 길어져 `다음` 버튼이 메모판 아래로 잘렸다.
- 가설 카드를 2열로 재배치하고 완료 버튼 높이를 고정했다.
- 재캡처에서 팝업, 중앙 경로, 우측 증거, 메모판, 안내 말풍선 사이의 겹침·잘림이 없음을 확인했다.

## 자동 검증

- `npm test`: 45/45 통과
- `npm run build`: 통과
- 배치·2줄 라벨·메모판 문구를 회귀 테스트로 고정했다.

## 남은 범위

- 현재의 단계형 측정/판정은 유지했다. 자유 배치 카드 사이를 사용자가 직접 붉은 실로 잇는 확장은 후속 범위로 추적한다.
