# TraceBack 사내 AI 공모전 제출 체크리스트

## 권장 응모 부문

`개발과 검증`

TraceBack은 자동차 도메인 학습과 검증 사고를 웹 게임으로 실행하는 사례입니다. 게임 자체보다 차량 구조·E/E 신호·고장 원인 추적·정상 로직 구성·시험 결과 판단을 다른 구성원이 직접 경험할 수 있다는 점을 중심으로 설명합니다.

## 게시글 필수 항목

- 닉네임: 익명 AI 활용 사례
- 업무: 자동차 도메인 학습과 검증 사고를 위한 교육 콘텐츠 제작
- 개선: 문서 중심의 차량 학습을 관찰·추적·조립·비교의 실행 흐름으로 전환
- 활용: 정비소 → 레이싱 → 도미노 추적 → 정상 로직 퍼즐 → 실험 검증
- 사용법: 공개 랜딩페이지 접속 → 게임 실행 → PC 키보드로 플레이 → 단계별 결과 확인
- 공개 설정: 반드시 `공개`

GitHub·Notion·에이전트 파일·스킬 파일은 필수 형식이 아닙니다. 실제로 공개할 저장소나 페이지가 준비되지 않았다면 임의의 링크를 만들지 않고, 실행 링크·영상·캡처·설명자료를 조합하는 편이 안전합니다. 슬라이드나 문서는 선택 자료로 추가할 수 있습니다.

## 사용 안내

- 환경: PC Chrome 권장
- 조작: 기존 게임의 키보드 주행 구조에 맞춰 PC 플레이 권장
- 모바일: 랜딩페이지와 영상 열람은 가능하지만 게임 플레이는 PC 권장
- 순서: 정비소에서 구조·신호 기준 확인 → 레이싱에서 이상 증상 관찰 → 도미노에서 최초 편차 추적 → 퍼즐에서 정상 로직 조립 → 검증에서 정상·고장 비교
- 공유 시: 게임 링크, 랜딩페이지 링크, 시연영상, 단계별 화면을 함께 제공

## 정적 호스팅 유지 메모

공개 URL은 사용자의 노트북이 서버가 되어 실행되는 방식이 아니라 원격 정적 호스팅에서 파일을 제공하는 방식입니다. 따라서 노트북을 꺼도 링크는 계속 열립니다. 다만 호스팅 서비스의 운영 정책·쿼터·프로젝트 보존 조건에 따라 영구 제공을 보장할 수는 없으므로, 평가가 끝날 때까지 프로젝트를 삭제하거나 비공개로 전환하지 않고 링크 응답을 주기적으로 확인합니다.
