# 게시판에 붙여넣을 파일

**`iframe-embed.html` 전체를 복사합니다.** 파일 이름은 그대로지만, 이제 홍보 글 전체를 iframe에 넣는 방식이 아닙니다. 본문은 게시판 길이만큼 펼쳐지고 실제 게임 화면 하나만 16:9 iframe으로 들어갑니다.

## 적용 방법

1. `iframe-embed.html`을 메모장 또는 VS Code로 엽니다.
2. `Ctrl+A → Ctrl+C`로 HTML 코드 전체를 복사합니다.
3. 기존 게시글의 HTML 소스 모드에서 이전 홍보 페이지 iframe 블록을 이 코드로 교체합니다. 직접 작성한 인사말 등은 남겨 둡니다.
4. 저장 후 실제 게시글에서 이미지, 영상, 게임을 확인합니다. 편집 화면의 IFRAME 상자는 실제 게임 대신 보이는 편집기 표시일 수 있습니다.

HTML 파일을 첨부할 필요는 없습니다. 이미지·영상·게임은 코드에 들어 있는 공개 HTTPS 주소에서 불러옵니다.

`board-preview.html`을 브라우저에서 열면 본문 형태를 미리 볼 수 있습니다. 이 미리보기는 게시판 자체의 필터링까지 재현하지는 않습니다. 게시판이 video 태그를 제거하는 경우를 위해 영상 직접 열기 링크도 표시합니다. 게임 아래에는 새 창 링크가 있습니다.

## 문구·이미지 수정

- 원본: `promotion/landing-embed/index.html`
- 수정 후 `promotion/tools` 폴더에서 `npm run build`를 실행하면 게시판 파일을 다시 만듭니다. 최초 설정 시에는 해당 폴더에서 `npm ci`를 먼저 실행합니다.
- 변환은 문구와 섹션 순서를 유지하며 게시판용 스타일을 각 요소에 직접 넣습니다. 게시판 JavaScript에 의존하지 않습니다.
- 본문 문구, 섹션 번호, 이미지 주소를 바꾼 경우 새 코드를 게시글에 다시 붙여 넣습니다.
- 같은 URL의 게임·이미지·영상 파일만 업데이트한 경우 공개 호스팅에 재배포하면 됩니다. 로컬 저장만으로 공개 사이트가 바뀌지는 않습니다.

이번 전환은 게시글 본문의 구조 자체를 바꾸므로 기존 게시글에 코드를 **한 번 다시 붙여 넣어야** 합니다. 공개 사이트 재배포만으로 기존 920px짜리 iframe이 펼쳐진 본문으로 바뀌지는 않습니다.

## 파일 구분

- `iframe-embed.html`: 최종 복사용 HTML 본문.
- `board-public.html`: 위 파일과 같은 내용의 사본.
- `board-preview.html`: 로컬 브라우저 확인용.
- `landing-iframe-legacy.html`: 이전의 전체 페이지 iframe 방식 백업.
- `board.html`: 과거 게시판 초안. 현재 게시글에는 사용하지 않습니다.
