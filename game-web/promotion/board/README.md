# 게시판용 TraceBack HTML

`board.html`은 사내 게시판에 붙여 넣기 위한 별도 버전입니다.

## 바로 복붙할 파일

`board-public.html`을 사용합니다. 이미지·영상 경로가 공개 배포 URL로 들어 있어 게시판에 에셋 파일을 따로 업로드하지 않아도 됩니다.

1. 파일을 브라우저가 아니라 메모장 또는 VS Code로 엽니다. 브라우저에서 보이는 화면을 복사하면 HTML 코드가 아닙니다.
2. 파일 전체를 `Ctrl+A → Ctrl+C` 합니다.
3. 게시판 글쓰기 화면에서 `HTML`, `소스`, `<>` 또는 `HTML 편집` 모드로 전환합니다.
4. 붙여 넣고 미리보기에서 확인합니다.
5. 게시판이 `<html>`, `<head>`, `<style>`을 제거하면 `<body>` 안의 `<article class="tb-board">...</article>` 부분과 `<style>` 블록만 남겨 다시 붙여 넣습니다.

일반 글쓰기 화면에 코드를 그대로 붙여 넣으면 코드가 글자로 보일 수 있습니다. 반드시 HTML 소스 편집 모드가 필요합니다.

## iframe 방식

게시판에 이미지 파일을 하나씩 업로드하기 어렵다면 `iframe-embed.html`을 우선 시도합니다. 이 파일은 에셋을 포함하지 않고 공개 랜딩페이지를 불러오기 때문에 이미지 경로가 누락되지 않습니다.

1. `iframe-embed.html`을 메모장 또는 VS Code로 엽니다.
2. 전체 코드를 복사합니다.
3. 게시판의 HTML 소스 모드에 붙여 넣습니다.
4. 게시판이 iframe을 허용하면 페이지가 표시됩니다.

iframe이 보이지 않으면 게시판 보안 정책이 iframe을 제거하는 것입니다. 이 경우 `board-public.html`을 사용하거나 공개 랜딩페이지 링크를 본문에 직접 넣어야 합니다. iframe 내부 높이는 920px로 설정되어 있으며, 모바일에서는 내부 스크롤이 생길 수 있습니다.

## 적용 전 설정

1. `board.html`을 직접 사용할 경우 `../assets/`의 이미지 파일을 게시판이 허용하는 이미지 저장소에 업로드하고 경로를 교체합니다.
2. 공개 URL을 그대로 쓰려면 `board-public.html`을 사용합니다.
3. 게시판이 `<style>`, `background-image`, 외부 이미지·동영상 도메인, `aria-*` 속성을 제거하는지 테스트합니다.

시연영상은 `<video controls>`로 포함했지만 게시판이 동영상 태그를 차단하면 해당 블록을 제거하거나 사내 허용 동영상 URL로 교체합니다. 게시판 버전은 iframe·JavaScript를 사용하지 않으므로 페이지 안에서 게임을 직접 실행하지 않습니다. iframe 방식은 `iframe-embed.html`에서 공개 랜딩페이지를 불러오며, 페이지 안의 `게임 열기` 버튼은 공개 게임 실행 영역으로 연결됩니다.

`board-public.html`은 외부 JavaScript와 iframe을 사용하지 않으며, 모바일에서는 게임 플레이가 아니라 홍보 콘텐츠 열람에 초점을 둡니다. `iframe-embed.html`은 별도 iframe 허용이 필요한 대안입니다.
